\section*{Solution}
The logic function given by the circuit is:
\[
Y = AB + CD
\]
This means the output \(Y\) is high when either both \(A\) and \(B\) are high or both \(C\) and \(D\) are high. The solution involves implementing this equation using Arduino and hardware (7447 IC). The function was verified by constructing the truth table and tested in the PlatformIO environment.

\section*{Steps to Execute in PlatformIO}
\begin{enumerate}
    \item Install PlatformIO in your chosen development environment.
    \item Initialize a new project for Arduino UNO:
        \begin{verbatim}
        pio project init --board uno
        \end{verbatim}
    \item Place the Arduino code implementing the equation \(Y = AB + CD\) in \texttt{src/main.cpp}.
    \item Build the project:
        \begin{verbatim}
        pio run
        \end{verbatim}
    \item On Android Termux, transfer the compiled firmware to ArduinoDroid:
        \begin{verbatim}
        cp .pio/build/uno/firmware.hex /sdcard/ArduinoDroid/sketch/sketch7447/sketch.hex
        \end{verbatim}
    \item Upload the code via ArduinoDroid or use PlatformIO upload on PC.
    \item Verify output on the 7-segment display connected to the 7447 driver IC.
\end{enumerate}

\section*{Conclusion}
This report demonstrated the implementation of the logic function \(Y = AB + CD\) using Arduino and a 7447 BCD to 7-segment driver IC. The function was validated through a truth table and verified in hardware using PlatformIO workflow. This process confirms practical embedded system applications of combinational logic design.
