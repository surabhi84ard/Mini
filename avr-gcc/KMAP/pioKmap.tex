\section*{Abstract}

\section{Karnaugh Map Minimization}

\subsection*{Output A}
Boolean expression:


\[
A = W'X'Y'Z' + W'XY'Z' + W'X'YZ' + W'XYZ' + W'X'Y'Z
\]


Minimized using K-map:


\[
A = W'Z' + W'X'Y'
\]



\subsection*{Output B}
Boolean expression:


\[
B = WX'Y'Z' + W'XY'Z' + WX'YZ' + W'XYZ'
\]


Minimized:


\[
B = WX'Z' + W'XZ'
\]



\subsection*{Output C}
Boolean expression:


\[
C = WXY'Z' + W'X'YZ' + WX'YZ' + W'XYZ'
\]


Minimized:


\[
C = WXY'Z' + X'YZ' + W'YZ'
\]



\subsection*{Output D}
Boolean expression:


\[
D = WXYZ' + W'X'Y'Z
\]


Minimized using K-map directly.
