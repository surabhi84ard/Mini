\section{5G NR L2/L3 Protocols}

5G NR L2/L3 handles signaling, QoS, reliability and scheduling between UE and gNB.

\subsection{RRC (L3) - Key Functions}
\begin{itemize}
  \item Broadcasts MIB/SIBs for system info
  \item Manages RRC states: IDLE/INACTIVE/CONNECTED
  \item Connection setup/reconfig/release
  \item Security activation, bearer control
  \item Handover/measurement configuration
\end{itemize}

\subsection{RLC (L2) - Transfer Modes}
\begin{itemize}
  \item \textbf{TM}: No header/ARQ (control channels)
  \item \textbf{UM}: Unacked, low latency, reordering
  \item \textbf{AM}: ARQ retransmissions, status reports
  \item Segmentation/concatenation/reassembly
\end{itemize}

\subsection{SDAP (L2) - QoS Mapping}
\begin{itemize}
  \item Maps QoS flows $\rightarrow$ DRBs using QFI
  \item Reflective QoS (UL mirrors DL rules)
  \item 1:1 or N:1 flow-to-bearer mapping
\end{itemize}

\subsection{MAC (L2) - Scheduling}
\begin{itemize}
  \item Logical $\rightarrow$ transport channel mapping
  \item Multiplexing, HARQ coordination
  \item Buffer status reports, scheduling requests
\end{itemize}

\subsection{Advanced MAC Features}
\begin{itemize}
  \item Proportional fair/QoS-aware scheduling
  \item Configured grant (Type 1/2) for URLLC
  \item Carrier aggregation, DRX power saving
  \item Beam failure recovery
\end{itemize}
