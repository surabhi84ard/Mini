Q2: Note down the differences between Call by Value and Call by Reference and when to use what.

-> Call by Value:
. A copy of the variable is passed to the function.

. Changes made inside the function do not affect the original variable.

. Safe from unintended side effects.

. Slightly slower for large data (due to copying).

. Ideal for read-only operations or temporary calculations.

. Syntax: void func(int x); -> called as func(a);

-> Call by Reference
. The address of the variable is passed to the function.

. Changes made inside the function directly affect the original variable.

. Efficient for large data structures (no copying).

. Can be riskier if not handled carefully (side effects).

. Useful when you need to modify values or return multiple results.

. Syntax: void func(int *x); → called as func(&a);


When to Use?
-> Use Call by Value when:

. You want to protect original data.

. You're working with simple types like int, char, float.

. You only need the value for computation, not modification.

-> Use Call by Reference when:

. You need to update the original variable.

. You're working with arrays, structs, or large data.

. You want to return multiple outputs from a function.
