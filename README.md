# FWC Course Work – IIITB COMET Foundation

This repository contains the coursework, assignments, experiments, and mini-projects completed as part of the **Foundations of Wireless Communications (FWC)** course under the **IIIT Bangalore COMET Foundation Program**.

The repository includes work across multiple domains such as:

- Embedded Systems
- Digital Electronics
- FPGA/Verilog
- ESP32 Programming
- AVR-GCC
- Assembly Programming
- Signal Processing Concepts
- Mathematical Simulations
- Hardware Interfacing
- Python-based Embedded Development

---

# Repository Structure

## 📁 Assembly
Programs and experiments related to low-level assembly language concepts.

## 📁 Gate
Gate exam papers exercise.

## 📁 Vaman_gate
Gate-level design implementations and related hardware exercises using VAMAN board.

## 📁 avr-gcc
Embedded C programs developed using AVR-GCC toolchain.

## 📁 esp32
ESP32-based hardware interfacing and IoT-related experiments.

## 📁 imo
Indian math olympiad papers exercise.

## 📁 latex_setup
LaTeX setup files and documentation-related resources.

## 📁 maths
Mathematical derivations, simulations, and analytical work.

## 📁 pico
Projects and experiments using Raspberry Pi Pico.

## 📁 platformio
Embedded development projects using PlatformIO.
